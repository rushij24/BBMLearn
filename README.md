# BBMLearn

A modern learning management web application built with TypeScript, Vite, and Tailwind CSS.

🌐 **Live:** [bbm-learn.vercel.app](https://bbm-learn.vercel.app)

---

## About

BBMLearn is a web-based learning platform designed to deliver structured educational content with a clean, responsive UI.

---

## Tech Stack

- **TypeScript** — Type-safe application code
- **Vite** — Fast build tooling and dev server
- **Tailwind CSS** — Utility-first responsive styling
- **PostCSS** — CSS processing pipeline
- **ESLint** — Code quality enforcement

---

## Getting Started

```bash
# Clone the repo
git clone https://github.com/rushij24/BBMLearn.git
cd BBMLearn

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```
